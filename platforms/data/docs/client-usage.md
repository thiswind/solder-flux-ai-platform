# 客户使用说明

## 客户应该看什么

客户不需要查看以下内容：

- `excel/` 下的原始 Excel
- `image/` 下的中间脚本和中间结果
- `yunxi_data_platform/` 下的历史处理代码

客户只需要看：

- 云锡数据管理系统前端页面

## 页面说明

### 1. 系统总览

看什么：

- 最近一次数据处理任务是否成功
- 当前系统处理了多少条总体记录、详细记录
- 当前有多少待复核问题
- 各类数据集规模

### 2. 任务运行

看什么：

- 当前是否执行新的数据处理任务
- 最近任务列表

这个页面通常由内部管理员使用，不建议客户频繁操作。

### 3. 数据集浏览

看什么：

- 系统已经结构化好的批次数据
- 化学成分
- 粒度分布
- 质量指标

这里已经是结构化后的结果，不是原始 Excel。

### 4. 复核问题

看什么：

- 哪些记录需要人工检查
- 哪些字段缺失
- 哪些批次未匹配成功

### 5. 数据源清单

看什么：

- 当前阶段系统已纳入管理的原始 Excel 文件

说明：

- 图片链路当前已暂时关闭
- 这一阶段先保证文本数据处理稳定，再恢复图片关联

## 客户不需要理解的内容

以下内容属于系统内部实现：

- 中间宽表
- 旧版 ETL 脚本
- sqlite 或 PostgreSQL 的底层表结构
- 前后端代码目录

## 一句话原则

客户只看页面，不看中间表。
